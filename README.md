# gEDES-HM

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21534586.svg)](https://doi.org/10.5281/zenodo.21534586)

Homology modeling and HADDOCK3 docking of adenylate kinases.

gEDES-HM transfers a conformational ensemble generated by enhanced-sampling
simulation of one protein to its homologues by multi-template homology
modeling. This repository holds the scripts, modeling inputs, docking results
and analysis data for its validation on 22 adenylate kinase homologues.

The ensemble itself comes from the gEDES protocol:
[vargiulab/gEDES](https://github.com/vargiulab/gEDES),
[Basciu et al., J. Chem. Inf. Model. 2025](https://doi.org/10.1021/acs.jcim.4c01810).

## GitHub and Zenodo

The complete archive is on Zenodo:
[10.5281/zenodo.21534586](https://doi.org/10.5281/zenodo.21534586). This
repository has the same layout, without the structure ensembles, which are too
large for git (710 MB).

| | GitHub | Zenodo |
| --- | --- | --- |
| `scripts/`, `analysis/`, `docking/` | yes | yes |
| `proteins_structural_models/`: MODELLER drivers, alignments, RMSD wrappers | yes | yes |
| `proteins_structural_models/`: templates, models, references (`*.pdb.gz`) | no | yes |

To run the steps that need the structures, download
`proteins_structural_models.zip` from Zenodo and unpack it at the top of this
repository:

```bash
curl -L -o proteins_structural_models.zip https://zenodo.org/records/21534586/files/proteins_structural_models.zip
unzip -n proteins_structural_models.zip
```

These work from this repository alone:

```bash
cd analysis/tableS6_check && bash check_tableS6.sh
cd analysis/statistics && python3 gEDES_SI_statistics.py
```

## The four receptor conditions

| Label | Where | Receptors per target |
| --- | --- | --- |
| **HM_gEDES** | `gEDES/`, `docking/<n>_*` | 101 homology models from the gEDES representatives, DOPE-selected |
| **HM_4AKE(apo)** | `apo/`, `docking/APO_*` | 10 models from the single apo template, PDB 4AKE |
| **HM_1AKE(holo)** | `holo/`, `docking/HOLO-1ake_*` | 10 models from the single holo template, PDB 1AKE |
| **HOLO_expt** | `docking/redocking_HOLO-expt_*` | 1, the target's own experimental holo receptor, ligand removed |

The first two were in the original submission. `HM_1AKE(holo)` and `HOLO_expt`
were added in revision as controls: the first bounds what the transferred
ensemble can achieve given an experimental bound structure of the reference
protein, which a prospective application would not have; the second is the
redocking ceiling and the noise floor of the RMSD metrics.

## 22 systems, 26 complexes

Files are keyed by system number, 1 to 22. Four targets carry two ligands each
and were docked as separate complexes, so a ligand suffix distinguishes them:
system 2 `_ADP` / `_AMP`, system 9 `_ADP` / `_AMP`, system 15 `_ADP182` /
`_ADP183`, system 21 `_ADP214` / `_ADP215`. That is why the 22 systems give 26
complexes throughout.

## Notes

- Structures are PDB format, many gzipped; `.tsv` files are tab separated.
- The binding-site definition for a given target is the `BS_RESIDUES` value in
  its `run_calc_rmsd-cpptraj*.sh`, and is the same at the modeling and the
  docking stage.
- Nothing under `analysis/` contains an absolute path. Set `ADK_ARCHIVE_ROOT`
  only if you separate it from the rest of the archive.
